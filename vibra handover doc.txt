## 1. PROJECT OVERVIEW

### What is VIBRA?

VIBRA is a Nigerian dating and social platform that solves three core problems:

| Problem | Solution |
| :--- | :--- |
| **Catfish/Fake Profiles** | Opay/NIN verification kills fake identities |
| **Time-wasters** | Free chat exists, but serious users pay with gifts |
| **"Who will pay?"** | Users prove intent with gifts. Recipients get real value. |

### Core Promise

> "Tinder = Foreign + Dry + Full of fakes"
> "Vibra = Nigerian + Verified + 'My date was actually paid for'"

### Brand

**Name Origin:** VIB + Naira = VIBRA  
**Tagline:** Connect. Vibe. Love.  
**Colors:** Purple (#6C3CE1) + Green (#00B894)

## 2. CORE CONCEPT & PROMISE

### The Level Hierarchy (Gamification)

| Level | Badge | How to Achieve | Perks |
| :--- | :--- | :--- | :--- |
| **Bronze** | 🥉 | Default (or 1,000 points) | Basic profile, chat |
| **Silver** | 🥈 | 10,000 points OR ₦5,000 OR send ₦20,000 in gifts | 5 photos, 1 boost/week |
| **Gold** | 🥇 | 25,000 points OR ₦12,000 OR send ₦50,000 in gifts | 10 photos, 3 boosts/week, priority inbox |
| **Platinum** | 💎 | 50,000 points OR ₦25,000 OR send ₦100,000 in gifts | Unlimited photos, free Premium |
| **Diamond** | 💎 | 100,000 points OR ₦50,000 OR send ₦200,000 in gifts | Exclusive badge, VIP events |

### Revenue Streams

| Stream | Rate | How It Works |
| :--- | :--- | :--- |
| Gift Commission | 20% | User buys gift → Merchant gets 80% |
| Cash Gift Fee | 5% | User withdraws cash gift → 5% fee |
| Level Upgrades | 90% | Users buy levels directly |
| Boost & Spotlight | 95% | Be #1 profile in your city |
| Business Listing | ₦10,000/month | Featured merchant |
| Events | 20% | Commission on event entry gifts |

import React, { createContext, useState, useContext, useEffect, useCallback } from 'react';
import * as authService from '../services/authService';

const AuthContext = createContext(null);

export const AuthProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const [isLoading, setIsLoading] = useState(true);
  const [isAuthenticated, setIsAuthenticated] = useState(false);
  const [error, setError] = useState(null);

  useEffect(() => {
    const loadCachedUser = () => {
      try {
        const cached = authService.getCachedUser();
        const loggedIn = authService.isLoggedIn();
        
        if (cached && loggedIn) {
          setUser(cached);
          setIsAuthenticated(true);
        }
      } catch (err) {
        console.warn('Failed to load cached user:', err);
      } finally {
        setIsLoading(false);
      }
    };

    loadCachedUser();
  }, []);

  const loginWithOpay = useCallback(async (phone) => {
    setError(null);
    setIsLoading(true);
    
    try {
      const result = await authService.loginWithOpay(phone);
      if (result.success) {
        setUser(result.user);
        setIsAuthenticated(true);
        return { success: true, user: result.user };
      }
      return { success: false, error: 'Login failed' };
    } catch (err) {
      setError(err.message || 'Opay login failed');
      return { success: false, error: err.message };
    } finally {
      setIsLoading(false);
    }
  }, []);

  const loginWithNIN = useCallback(async (nin, phone) => {
    setError(null);
    setIsLoading(true);
    
    try {
      const result = await authService.loginWithNIN(nin, phone);
      if (result.success) {
        setUser(result.user);
        setIsAuthenticated(true);
        return { success: true, user: result.user, note: result.note };
      }
      return { success: false, error: 'NIN login failed' };
    } catch (err) {
      setError(err.message || 'NIN login failed');
      return { success: false, error: err.message };
    } finally {
      setIsLoading(false);
    }
  }, []);

  const logout = useCallback(() => {
    authService.logout();
    setUser(null);
    setIsAuthenticated(false);
    setError(null);
  }, []);

  const updateUser = useCallback((updates) => {
    const updated = authService.updateCachedUser(updates);
    if (updated) {
      setUser(updated);
    }
    return updated;
  }, []);

  const checkOpayStatus = useCallback(async () => {
    return await authService.checkOpayStatus();
  }, []);

  const value = {
    user,
    isAuthenticated,
    isLoading,
    error,
    loginWithOpay,
    loginWithNIN,
    logout,
    updateUser,
    checkOpayStatus,
  };

  return (
    <AuthContext.Provider value={value}>
      {children}
    </AuthContext.Provider>
  );
};

export const useAuth = () => {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth must be used within an AuthProvider');
  }
  return context;
};

  } catch {
    return false;

    return null;

**Symptoms:** Blank page or white screen

**Solutions:**
1. Check `index.html` exists

**Symptoms:** Network errors or timeouts

**Solutions:**

DEVELOPER BLUEPRINT: ZERO-COST WALLET INTEGRATION & MANDATORY IDENTITY LOCK

1. HOSTING ENVIRONMENT (TRUEHOST CPANEL):
- Target Domain: vibra.ng
- Database: MySQL (Create via cPanel MySQL Database Wizard).
- Backend Language: PHP or Node.js (via cPanel "Setup Node.js App").

2. DATABASE SCHEMA DESIGN ('users' table):
- id (INT, Primary Key, Auto Increment)
- registration_name (VARCHAR) <-- Name they choose at free signup
- verified_legal_name (VARCHAR, Default NULL) <-- Sourced from OPay
- is_identity_locked (TINYINT, Default 0)
- wallet_balance_points (DECIMAL)

3. API LOGIC FLOW (DURING WALLET TRANSACTION):
- When a user attempts to execute a points-to-cash payout OR buy points using OPay:
  a) Take the user's OPay Account Number.
  b) Trigger the OPay Account Validation / Name Enquiry API endpoint.
  c) Extract the 'accountName' string from the OPay JSON payload response.

4. AUTOMATED PROFILE ENFORCEMENT RULES:
- IF 'is_identity_locked' == 0:
    * Overwrite 'registration_name' with the OPay 'accountName'.
    * Save 'accountName' into 'verified_legal_name'.
    * Set 'is_identity_locked' = 1.
    * Process transaction.
- IF 'is_identity_locked' == 1:
    * Run a strict server-side string match between the incoming OPay 'accountName' and the saved 'verified_legal_name'.
    * IF names DO NOT match, terminate execution, block the transaction, and flag the account. (Prevents a single scammer from routing funds through multiple victims' bank accounts).

5. TRANSACTION FEES:
- Implement client-side and server-side fee passing. 
- Deduct OPay's base transfer fee (e.g., ₦5 for OPay, ₦10-₦50 for other banks) plus your minor platform server upkeep buffer directly from the user's points balance before sending the final amount to the OPay payout payload.


To make sure genuine users are not startled when their profile name suddenly changes to their legal name, display this clear disclaimer inside the app's wallet page:🔒 Security & Verification NoticeTo maintain a safe dating ecosystem and eliminate scammers, Vibra uses automated banking verification.
