## 1. PROJECT OVERVIEW

### What is VIBRA?

VIBRA is a Nigerian dating and social platform that solves three core problems:

| Problem | Solution |
| :--- | :--- |
| **Catfish/Fake Profiles** | Opay/NIN verification kills fake identities |
| **Time-wasters** | Free chat exists, but serious users pay with gifts |
| **"Who will pay?"** | Users prove intent with gifts. Recipients get real value. |

### Brand
- **Name Origin:** VIB + Naira = VIBRA
- **Tagline:** Connect. Vibe. Love.
- **Colors:** Purple (#6C3CE1) + Green (#00B894)
- **Credit:** Powered by LabelReach

## 9. DATABASE SCHEMA

### 9.1 Users Table

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    userId VARCHAR(20) UNIQUE NOT NULL,
    phone VARCHAR(20) UNIQUE NOT NULL,
    registration_name VARCHAR(100) NOT NULL,
    verifiedLegalName VARCHAR(100) DEFAULT NULL,
    isIdentityLocked TINYINT(1) DEFAULT 0,
    level VARCHAR(20) DEFAULT 'Bronze',
    points DECIMAL(10,2) DEFAULT 0,
    isVerified TINYINT(1) DEFAULT 0,
    hasWithdrawn TINYINT(1) DEFAULT 0,
    isFounder TINYINT(1) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active',
    bio TEXT DEFAULT NULL,
    age INT DEFAULT NULL,
    gender VARCHAR(20) DEFAULT NULL,
    location VARCHAR(100) DEFAULT NULL,
    interests TEXT DEFAULT NULL,
    photos TEXT DEFAULT NULL,
    vibraScore DECIMAL(3,2) DEFAULT 3.5,
    createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    login_pin VARCHAR(4) DEFAULT NULL,
    pin_enabled TINYINT(1) DEFAULT 0,
    date_of_birth DATE DEFAULT NULL,
    life_goals VARCHAR(255) DEFAULT NULL,
    dealbreakers VARCHAR(255) DEFAULT NULL,
    dating_pace VARCHAR(50) DEFAULT NULL,
    lifestyle VARCHAR(50) DEFAULT NULL,
    referral_code VARCHAR(10) UNIQUE DEFAULT NULL,
    total_referrals INT DEFAULT 0,
    referral_redeemed_by VARCHAR(20) DEFAULT NULL,
    INDEX idx_phone (phone),
    INDEX idx_userId (userId),
    INDEX idx_level (level),
    INDEX idx_status (status)
);
```

### 9.2 Messages Table

```sql
CREATE TABLE messages (
    id VARCHAR(50) PRIMARY KEY,
    conversation_id VARCHAR(50) NOT NULL,
    sender_id INT NOT NULL,
    text TEXT NOT NULL,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_read TINYINT(1) DEFAULT 0,
    INDEX idx_conversation (conversation_id),
    INDEX idx_sender (sender_id)
);
```

### 9.3 Conversations Table

```sql
CREATE TABLE conversations (
    id VARCHAR(50) PRIMARY KEY,
    participants TEXT NOT NULL,
    last_message TEXT DEFAULT NULL,
    last_message_time TIMESTAMP NULL DEFAULT NULL,
    unread_count TEXT DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 9.4 Points History Table

```sql
CREATE TABLE points_history (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    points INT NOT NULL,
    source VARCHAR(50) NOT NULL,
    description TEXT DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_source (source)
);
```

### 9.5 Gifts Table

```sql
CREATE TABLE gifts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    gift_id VARCHAR(50) NOT NULL,
    gift_name VARCHAR(100) NOT NULL,
    gift_type VARCHAR(20) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    sender_id INT NOT NULL,
    recipient_id INT NOT NULL,
    message TEXT DEFAULT NULL,
    redemption_code VARCHAR(10) UNIQUE NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    merchant_id INT DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    redeemed_at TIMESTAMP NULL DEFAULT NULL
);
```

### 9.6 Events Table

```sql
CREATE TABLE events (
    id INT AUTO_INCREMENT PRIMARY KEY,
    host_id INT NOT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT DEFAULT NULL,
    event_date DATE NOT NULL,
    event_time TIME NOT NULL,
    location VARCHAR(255) NOT NULL,
    max_guests INT DEFAULT 50,
    type VARCHAR(20) DEFAULT 'open',
    entry_gift VARCHAR(50) DEFAULT NULL,
    entry_gift_price DECIMAL(10,2) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'active',
    invited_users TEXT DEFAULT NULL,
    attendees TEXT DEFAULT NULL,
    attendee_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 9.7 Merchants Table

```sql
CREATE TABLE merchants (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(20) NOT NULL,
    location VARCHAR(255) NOT NULL,
    category VARCHAR(50) NOT NULL,
    bvn VARCHAR(20) NOT NULL,
    user_id INT NOT NULL,
    status VARCHAR(20) DEFAULT 'active',
    verification_status VARCHAR(20) DEFAULT 'pending',
    total_redemptions INT DEFAULT 0,
    total_revenue DECIMAL(10,2) DEFAULT 0,
    trust_level VARCHAR(20) DEFAULT 'new',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 9.8 VIP Codes Table

```sql
CREATE TABLE vip_codes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    level VARCHAR(20) NOT NULL,
    points INT NOT NULL,
    recipient_phone VARCHAR(20) DEFAULT NULL,
    used TINYINT(1) DEFAULT 0,
    used_by INT DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_by INT DEFAULT NULL
);
```

### 9.9 System Logs Table

```sql
CREATE TABLE system_logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    action VARCHAR(100) NOT NULL,
    details TEXT DEFAULT NULL,
    user_id VARCHAR(50) DEFAULT NULL,
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
```

## 15. TROUBLESHOOTING GUIDE

### Issue: Page Blank
**Solution:** Clear browser cache or open incognito mode
```cmd
Ctrl + Shift + R
```

### Issue: CORS Error
**Solution:** Check config.php CORS headers
```php
header('Access-Control-Allow-Origin: *');
```

### Issue: API 404
**Solution:** Check file exists in `/public_html/api.vibra.ng/api/`

### Issue: PIN Flow Flashes
**Solution:** Check AuthContext.jsx `requiresPin` state

### Issue: Admin Access Denied
**Solution:** Run in console to set founder:
```javascript
const user = JSON.parse(localStorage.getItem('vibra_user'));
user.isFounder = true;
localStorage.setItem('vibra_user', JSON.stringify(user));
location.reload();
```
